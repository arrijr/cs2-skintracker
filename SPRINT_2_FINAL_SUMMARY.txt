TECHNICAL DECISIONS
================================================================================

1. Services Pattern: Business logic in services, controllers thin
   → Reason: Reusable, testable, maintainable

2. Heuristic-based Research: No AI/ML, pure calculations
   → Reason: Faster, simpler, deterministic, as specified

3. REST API (not GraphQL): Simpler for MVP
   → Reason: Sufficient for current needs, can add GraphQL later

4. Recharts for Charts: Industry standard, responsive
   → Reason: Well-maintained, good docs, mobile support

5. Tier Gating in Middleware: Checked on every request
   → Reason: Secure, consistent, prevents data leaks
