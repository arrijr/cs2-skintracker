## Don'ts

- Don't post in `#trading`, `#deals`, `#general` unless explicitly allowed
- Don't @everyone or @here ever
- Don't post the same message in multiple channels of the same server
- Don't argue with skeptics — engage politely, fix what's valid
- Don't post on launch day in 5 servers at once — looks coordinated/spammy
