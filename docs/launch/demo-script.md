# 60-Second Demo Video Script

**Tool:** Loom or QuickTime Screen Recording. 1080p, 30fps. Browser at 1280x800. No mouse cursor highlights needed.

**Audio:** Optional. If using narration, sound calm and confident — not corporate. If silent, use captions.

**Output:** `demo.mp4` for HN/Twitter, `demo.gif` (5-10 sec loop of dashboard) for Reddit.

---

## Storyboard

### 0:00–0:03 — Landing Page
- Open `https://skintrackr.com`
- Show hero: "The Robinhood for CS2 Skins"
- Caption (if silent): **"A portfolio tracker for serious CS2 traders"**

### 0:03–0:08 — Sign Up
- Click "Start Free"
- Clerk sign-in modal pops up
- Quick sign-up (use a pre-prepared test account to skip email)
- Caption: **"Free in 30 seconds"**

### 0:08–0:18 — Add Skins to Portfolio
- Land on dashboard (empty state)
- Click "Add to Portfolio" or navigate to `/portfolio`
- Add 2-3 popular skins (e.g., AK-47 Redline FT, M4A1-S Cyrex MW, Dragon Lore BS — show range)
- Quick fills: amount, buy price, buy date
- Caption: **"Track your real cost basis"**

### 0:18–0:35 — Dashboard with KPIs
- Navigate back to `/dashboard`
- Show: Total Value, Unrealized P&L, Allocation, Top Movers
- Hover on a KPI to show tooltip
- Show portfolio chart (any range)
- Caption: **"Real metrics. Live prices. Dark mode."**

### 0:35–0:45 — Pricing Page
- Click "View Plans" or navigate to `/pricing`
- Pan over the 3 tiers (Free / Lite / Pro)
- Hover the Pro card highlight
- Caption: **"Free forever. Premium from €4.99/mo."**

### 0:45–0:55 — Stripe Checkout
- Click "Choose Pro"
- Quick redirect to Stripe checkout (just a glimpse)
- Cut back to dashboard before payment completes
- Caption: **"Secure Stripe checkout"**

### 0:55–1:00 — Outro
- Back to landing page
- Static end card: skintrackr.com logo + URL + "Free forever for casual collectors"
- Caption: **"skintrackr.com"**

## Recording Tips

- **Pre-record the data:** add skins to a test account before recording so you don't fumble during capture
- **Use a fresh Chrome profile:** no extensions, no autofill clutter
- **Hide DevTools, hide bookmarks bar**
- **Cursor:** don't shake the mouse, move deliberately
- **Cut deadtime:** 1 second of "thinking" should become 0.2s in final cut
- **Music (optional):** epidemicsound.com — pick something low-energy, electronic, non-distracting
