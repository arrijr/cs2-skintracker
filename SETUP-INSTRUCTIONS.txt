PHASE 1: COLLECT AND SAVE PRODUCTION KEYS
================================================================================

STEP 1.1: Gather Production Keys
-----------------------------------

You need to collect two LIVE production keys (not TEST keys).

CLERK_SECRET_KEY:
1. Open: https://dashboard.clerk.com
2. Go to: Project Settings → API Keys
3. Find the SECRET KEY (live mode, starts with "sk_live_")
4. Copy it to clipboard
5. KEEP IT SAFE - you'll paste it in the next step

STRIPE_SECRET_KEY:
1. Open: https://dashboard.stripe.com
2. Go to: Developers → API Keys
3. Find the SECRET KEY under "Live keys" section
4. Copy it to clipboard (starts with "sk_live_")
5. KEEP IT SAFE - you'll paste it in the next step

STEP 1.2: Run Setup Script
-----------------------------------

This script will:
- Prompt you to paste CLERK_SECRET_KEY (appears as dots for security)
- Prompt you to paste STRIPE_SECRET_KEY (appears as dots for security)
- Validate both keys match the sk_live_ pattern
- Update .env file locally
- Commit to git
- Push to main branch
- Log all operations (NO keys in log)

TO RUN:
1. Open PowerShell (press Win+X, then "Windows PowerShell")
2. Run these commands:

   cd "C:\Users\Arthur\Documents\Coding\CS2 Skin Tracker"
   .\setup-production-secrets.ps1

WHAT TO EXPECT:
- Prompt 1: "Paste CLERK_SECRET_KEY" - paste the key, press Enter
  (key appears as dots, this is normal)
- Prompt 2: "Paste STRIPE_SECRET_KEY" - paste the key, press Enter
  (key appears as dots, this is normal)
- Script will show progress for each step
- Look for "✅" signs indicating success
- Script will push to git automatically

TROUBLESHOOTING PHASE 1:
- Key validation fails: Make sure you copied LIVE keys (sk_live_), not TEST (sk_test_)
- Git push fails: Run "git config user.email" and "git config user.name" first
- File not found: Make sure you're in the correct directory

LOG LOCATION:
File: C:\Users\Arthur\AppData\Roaming\Claude\local-agent-mode-sessions\...\outputs\production-setup-log.txt
(Shows all operations, no key values)

PHASE 2: VERIFY VERCEL DEPLOYMENT
================================================================================

After Phase 1 completes:

1. CHECK VERCEL AUTO-DEPLOY:
   - Go to: https://vercel.com/arrijrs-projects/cs2-skin-tracker/deployments
   - Look for the latest deployment
   - Wait for status to change from "Building" to "Ready"
   - Click on deployment to see build logs
   - Look for any errors (they'll be clearly marked)

2. VERIFY ENVIRONMENT VARIABLES IN VERCEL:
   - Go to: https://vercel.com/arrijrs-projects/cs2-skin-tracker/settings/environment-variables
   - Check that you see:
     ✅ CLERK_SECRET_KEY (production scope)
     ✅ STRIPE_SECRET_KEY (production scope)
     ✅ DATABASE_URL (should already be there)
     ✅ Other variables from Phase 1

3. GET LIVE DEPLOYMENT URL:
   - From the Vercel deployment page, copy the domain
   - Example: "cs2-skin-tracker-abc123.vercel.app"
   - You'll use this in Phase 3

TROUBLESHOOTING PHASE 2:
- Deployment still building: Wait a few more minutes
- Build failed: Check the build logs for errors
- Can't see environment variables: Refresh the page and verify again

================================================================================
PHASE 3: REGISTER STRIPE WEBHOOK (Claude will handle this)
================================================================================

Claude Code will:
1. Get your live Vercel URL from the deployment
2. Register webhook endpoint in Stripe Dashboard:
   - URL: https://<live-url>/api/v1/webhooks/stripe
   - Events: customer.subscription.updated, customer.subscription.deleted, charge.succeeded
3. Copy webhook signing secret (whsec_...)
4. Add to .env: STRIPE_WEBHOOK_SECRET=whsec_...
5. Commit and push to git

WHAT TO EXPECT:
- Claude will create a webhook automatically
- You'll see confirmation in the setup log
- Stripe Dashboard will show the webhook registered
